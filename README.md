
# Customer Queue Management System

A simple Customer Queue Management System built using C++.

## Features
- Add new customers to the queue.
- Serve the next customer.
- Show the next customer.
- Display all customers.
- Show the total number of customers.
- Exit the program.

## Data Structure
This project uses the **Queue** data structure.

It follows the **FIFO (First In, First Out)** principle.

## Technologies
- C++
- Standard Template Library (STL)

## Concepts Used
- Queue
- Loops
- Switch Statements
- Conditional Statements
- Functions and Strings
